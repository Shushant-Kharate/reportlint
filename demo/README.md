# ReportLint demonstration files

Upload `format_template.docx` in **Templates**, review its rules, and publish it. In **Check**, compare the two reports against that template:

| Report | Expected result |
| --- | --- |
| `correct_report.docx` | 100%, zero issues |
| `formatting_errors_report.docx` | About 34%, with font, size, spacing, margin and missing Methods issues |

The content is fictional. The files are generated by `scripts/create_demo_files.py`; see the root [README](../README.md) for full setup and run commands.
